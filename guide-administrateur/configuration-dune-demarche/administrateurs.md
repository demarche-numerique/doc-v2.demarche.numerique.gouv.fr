# Gérer les administrateurs de la démarche

Une démarche peut avoir plusieurs administrateurs. Tous ont les mêmes droits : ils peuvent modifier le formulaire, configurer la démarche et gérer les autres administrateurs.

Pour gérer les administrateurs, cliquez sur la tuile **« Administrateurs »** depuis la page de votre démarche.

## Ajouter un administrateur

Renseignez l'adresse électronique de la personne dans le champ **« Ajouter un administrateur »**, puis cliquez sur **« Ajouter comme administrateur »**.

{% hint style="warning" %}
La personne doit déjà avoir un compte administrateur sur demarche.numerique.gouv.fr. Si ce n'est pas le cas, un message vous l'indique : invitez-la à [demander un compte administrateur](../README.md).
{% endhint %}

## Consulter la liste des administrateurs

La liste affiche, pour chaque administrateur, son adresse électronique, sa date d'enregistrement et son état :

* **Actif** : la personne s'est déjà connectée ;
* **En attente** : la personne ne s'est pas encore connectée, et son invitation est toujours valable ;
* **Expiré** : la personne ne s'est jamais connectée, et son invitation n'est plus valable.

Votre propre adresse est suivie de la mention « (C'est vous !) ».

## Retirer un administrateur

Cliquez sur **« Retirer »** sur la ligne de l'administrateur, puis confirmez. Vous pouvez aussi vous retirer vous-même d'une démarche.

{% hint style="info" %}
Une démarche doit toujours garder **au moins un administrateur actif**. Le bouton « Retirer » n'apparaît donc pas lorsque l'administrateur concerné est le seul administrateur actif.
{% endhint %}

## Reprendre les administrateurs lors d'un clonage

Lorsque vous clonez une démarche dont vous êtes administrateur, l'option **« Administrateurs »**, cochée par défaut, permet de reprendre tous ses administrateurs dans la nouvelle démarche. Si vous la décochez, vous serez le seul administrateur de la copie.

Si vous clonez une démarche dont vous n'êtes pas administrateur, par exemple depuis l'annuaire des démarches, vous êtes le seul administrateur de la copie.
