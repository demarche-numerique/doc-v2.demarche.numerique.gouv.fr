# Retrouver ses démarches

Une fois connecté, vous arrivez sur la page **« Mes démarches »**. Elle liste les démarches dont vous êtes administrateur.

Pour créer une démarche, cliquez sur **« Nouvelle Démarche »**.

## Les onglets

Les démarches sont réparties en quatre onglets. Chacun indique le nombre de démarches qu'il contient :

* **publiées** : les démarches ouvertes aux usagers ;
* **en test** : les démarches pas encore publiées ;
* **terminées** : les démarches closes ;
* **supprimées** : les démarches que vous avez supprimées.

## Accéder directement à une démarche

Si vous avez plus de trois démarches, le champ **« Accès direct »** vous permet d'en ouvrir une rapidement. Chaque démarche y est présentée par son numéro et son libellé : tapez l'un ou l'autre pour la retrouver, puis sélectionnez-la.

## Ce qu'affiche chaque démarche

Pour chaque démarche, la liste affiche :

* son libellé, qui mène à sa page de gestion, et son lien public ;
* ses dates de création, de publication, de dernière modification et de clôture ;
* le nombre d'instructeurs, ou le nombre de groupes d'instructeurs si le routage est activé ;
* son numéro et son état.

Le bouton **« Modifier »** ouvre la page de gestion de la démarche. Le menu **« Actions »** propose, selon l'état de la démarche :

* **Tester** : ouvre la démarche comme un usager ;
* **Cloner** : crée une copie de la démarche ;
* **Supprimer** : pour une démarche qui n'est pas publiée ;
* **Clore** : pour une démarche publiée ;
* **Restaurer** : pour une démarche supprimée.

## Supprimer et restaurer une démarche

La suppression est définitive et s'applique à tous les administrateurs de la démarche. La démarche apparaît ensuite dans l'onglet « supprimées », où l'action **« Restaurer »** du menu « Actions » permet de la rétablir.
